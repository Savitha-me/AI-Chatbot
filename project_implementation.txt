Chunker.py:
  this file is for chunking the text after the chunking process we need to overlap the text. The overlap is important because without overlapping the connectivity between the chunks was lost
  CHUNK SIZES:
    1.Small Faq Documents : if it is a small document then the chunk size should be 300-500
    2.working on company policies files - the companu policy file has contents more then the small documents so chunk size is 800-1200
    3.books - getting the contents from the book then the chunk size is 1000-1500
    4.Research Papers - getting the contents from the research papers chunk size is 1500-2000
 the chunk size should not be very high and also should not be very low if the chunk size is very high it doesnot retrieve the contents correctly retrieves the more irrelevant contents and if 
 the chunk size is very less there is a breakage of sentence so we cannot properly fetch it
the chunk overlap should be 10per or 20 per from the chunk size if we choose 50per then there is a chance of overlapping the texts
